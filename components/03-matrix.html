Every row and every column totals 120 — the design is balanced, so no model, variant, or condition carries more weight than another in the aggregate. Instruction Accuracy and Intent Accuracy are near-mechanical and pre-filled. Plan Feasibility, Action Feasibility, and the two optimality metrics are scored by hand, because the distinction that matters — is a surplus action incorrect (it serves a different goal, so it enters the denominator) or merely inefficient (a valid alternative route to the same goal, so it does not) — is only visible against the grid.
