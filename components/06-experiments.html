What each condition tests. P1–P3 ask whether performance survives changes that should be irrelevant — a model that memorised surface patterns would break here, and a model that reasoned would not. P4 asks the converse: whether the grid is a real constraint at all. If a model reproduces the original answer after the keys have moved, it was never reading the grid. Together the four separate robustness from rigidity; either one alone is ambiguous.
